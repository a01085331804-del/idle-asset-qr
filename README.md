# 유휴 설비 QR 관리

- `index.html` : 전체 유휴 설비 관제 (KPI, 상태/위치별 현황, 검색·필터, 카드 목록)
- `admin.html` : 설비 등록/수정/삭제 + QR 생성·PNG 저장·라벨 인쇄 (비밀번호 필요)
- `view.html?id=…` : QR을 스캔하면 열리는 설비 상세
- DB : Google 스프레드시트 (`apps-script/Code.gs`가 시트·사진폴더를 자동 생성)

## 설치 (최초 1회, 약 10분)

### 1) 스프레드시트 + Apps Script
1. https://sheets.new 로 새 스프레드시트 생성 (이름 자유)
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 코드를 지우고 `apps-script/Code.gs` 전체를 붙여넣기
4. 맨 위 `ADMIN_PASSWORD = '1234'` 를 원하는 비밀번호로 변경
5. 상단 함수 선택에서 **setup** 선택 → ▶ 실행 → 권한 승인 (시트/사진폴더 자동 생성)
6. **배포 → 새 배포 → 유형: 웹 앱** → 실행 사용자 **나**, 액세스 **모든 사용자** → 배포
7. 나오는 **웹 앱 URL** 복사

### 2) config.js
`config.js`의 `API_URL: ''` 에 위 URL을 붙여넣기.

### 3) GitHub Pages
1. GitHub에서 새 저장소(Public) 생성 후 이 폴더의 파일을 업로드
   (`apps-script` 폴더는 올리지 않아도 됨)
2. 저장소 **Settings → Pages → Branch: main / (root)** 저장
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 로 접속 → 끝

> QR 주소는 현재 사이트 주소를 자동으로 사용하므로 별도 설정이 없습니다.
> 도메인이 바뀔 예정이면 `config.js`의 `BASE_URL`에 고정 주소를 넣으세요.

## 항목 추가/변경
스프레드시트의 **필드설정** 시트에 행을 추가/수정하면 등록 폼·상세·관제 화면에 자동 반영됩니다.

| 필드명 | 타입 | 옵션 |
|---|---|---|
| 설비명 | text | |
| 설비상태 | select | 유휴,재가동 검토,매각 예정,… |

타입: `text` `textarea` `number` `date` `select`(옵션 쉼표 구분) `image`
- 필드명 변경 시 기존 데이터는 **새 이름의 빈 컬럼**으로 분리됩니다. (옛 컬럼 값은 `설비` 시트에 남음 → 이름 변경보다 추가 권장)
- 핵심 필드 이름(설비명·설비상태 등)을 바꾸면 `config.js`의 `F` 항목도 같이 수정하세요.

## 참고
- 조회(관제/상세)는 누구나 가능, 등록·수정·삭제만 비밀번호가 필요합니다. 민감 정보는 넣지 마세요.
- Apps Script 코드를 수정하면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다. (URL 유지)
- 사진은 Drive의 `유휴설비_사진` 폴더에 저장됩니다.
